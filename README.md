# Information Security Projects Portfolio (Yandex Practicum)

Hi! My name is Ivan, and I am an Information Security Specialist (Penetration Tester / SOC). 

This repository contains my practical projects completed during the Yandex Practicum course. It demonstrates my hands-on skills in web application pentesting, infrastructure hardening, incident investigation, security auditing (FSTEC-21 compliance), and automation.

## Project Categories

### Web Application Pentesting & Security
*   **Web App Pentest (OWASP Juice Shop):** Exploitation of SQLi, XSS, IDOR, authentication bypass, and Path Traversal. WAF deployment and testing.
*   **Email Security:** Configuration of Postfix, SPF, DKIM, DMARC, and rspamd to prevent spoofing and phishing.

### Infrastructure Hardening & Automation
*   **Linux/Windows Hardening:** Configuration of PAM, sudo, auditd, sysctl, and GPO. FSTEC-21 compliance checks.
*   **Network Security:** Segmentation, routing, ACLs (Cisco Packet Tracer), and network traffic analysis.
*   **Ansible Automation:** Automation of DNS, NTP configuration, and backup routines.
*   **Linux Monitoring:** System monitoring (stress, ps, awk) and Bash scripting for cron jobs.

### Incident Response (IR) & SOC
*   **Incident Investigation:** Phishing analysis, detection of hidden cryptominers (XMRig in cron), and traffic analysis (Wireshark).
*   **Digital Forensics:** Artifact collection and analysis (FTK Imager, Volatility).

### Audit & Compliance
*   **Security Audit:** Infrastructure audit, configuration review, and development of a corporate security standard.
*   **FSTEC-21:** Compliance assessment and remediation planning.
