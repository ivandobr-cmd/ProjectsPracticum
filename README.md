# Information Security Projects Portfolio (Yandex Practicum)

Hi! My name is Ivan, and I am an Information Security Specialist (Penetration Tester / SOC). 

This repository contains my practical projects completed during the Yandex Practicum course. It demonstrates my hands-on skills in web application pentesting, infrastructure hardening, incident investigation, security auditing (FSTEC-21 compliance), and automation.


## Featured Projects

*   **[Incident Investigation (SOC)](https://github.com/ivandobr-cmd/ProjectsPracticum/blob/main/incident-investigation-and-traffic-analysis.pdf)**: Analyzed network traffic and logs to detect phishing, hidden XMRig cryptominers, and data exfiltration attempts, documenting the full attack timeline.
*   **[FSTEC-21 Compliance Audit](https://github.com/ivandobr-cmd/ProjectsPracticum/blob/main/fstec-21-compliance-and-remediation-plan.pdf)**: Audited a simulated infrastructure against FSTEC-21 requirements, identified critical misconfigurations, and created a step-by-step remediation plan.
*   **[Web App Pentest (OWASP Juice Shop)]()**: Exploited SQLi, XSS, and IDOR vulnerabilities, and deployed a WAF (BunkerWeb) that successfully blocked 100% of test attacks.
